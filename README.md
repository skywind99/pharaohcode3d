# 숫자 발굴 · 공중 유적

주사위 세 수로 식을 만들고, 입체 블럭 탑에서 목표 숫자를 발굴하는 수업용 연산 게임입니다.

기존 HTML 연산 게임을 바탕으로 3D 블럭, 회전 조작, 모바일 화면, 움직이는 배경과 발굴 효과를 추가하는 프로젝트입니다.

> 현재 상태: 통합 코드 작성 단계입니다.
> 브라우저·모바일 실기기 검증은 완료되지 않았습니다.
> 아래 기능은 통합 코드에 포함하도록 작성한 내용이며, 정상 동작을 보증하는 테스트 결과는 아닙니다.

---

## 1. 프로젝트 개요

- **대상:** 연산 활동에 참여하는 학생과 수업을 진행하는 교사
- **형태:** HTML·CSS·JavaScript 기반 웹 게임
- **목표:** 세 수를 조합하여 목표 숫자를 만들고 다양한 연산을 탐색하기
- **특징:** 입체 탑을 회전하며 숫자를 찾는 공간 탐색과 연산 활동 결합

---

## 2. 주요 기능

### 입체 숫자 블럭

- 둥근 모서리의 정육면체 블럭
- 블럭 여섯 면에 동일한 숫자와 점수 표시
- 등급별 색상 구분
- 다른 블럭에 가려진 면은 회전하여 확인
- 드래그와 짧은 클릭·터치를 구분하여 조작

### 다양한 판 모양

- 계단식 삼각뿔
- 나선 계단
- 양쪽 계단
- 다리
- 여러 봉우리

모양은 시드에 따라 자동으로 결정하거나 직접 선택할 수 있습니다.

### 두 가지 플레이 모드

| 모드 | 설명 |
|---|---|
| 식 만들기 | 블럭을 고른 뒤 주사위 숫자를 직접 조립하여 목표를 만듭니다. |
| 풀이 보기 | 만들 수 있는 블럭을 고르면 계산 과정을 확인하고 획득합니다. |

### 화면과 효과

- 공중 유적 테마의 메인 화면
- 천천히 움직이는 구름과 공중 섬
- 입체적인 주사위 표시와 굴림 효과
- 선택한 블럭 강조
- 발굴 성공 시 작은 큐브 조각 효과
- 보충 블럭 낙하 효과
- 덱 소진 후 반투명 와이어프레임 표시
- 배경 움직임 끄기 및 움직임 줄이기 설정 대응

### 경기와 결과

- 시드 기반 판·주사위 재현
- 2분·3분·5분 제한 시간
- 점수·발굴 수·굴림 수 표시
- 연산 종류별 발굴 집계
- 결과 복사
- Supabase 점수 제출
- 교사 순위표

## 3. 실행 방법

### 준비 사항

- 인터넷 연결
- WebGL과 ES module을 지원하는 최신 브라우저
- 전체 코드가 들어 있는 HTML 파일

Three.js를 CDN에서 불러오므로 기본 구성에서는 오프라인 실행을 지원하지 않습니다.

### 실행

1. 전체 코드를 `index.html` 또는 `숫자발굴-최종.html`로 저장합니다.
2. 로컬 웹 서버에서 실행하거나 정적 웹 호스팅에 배포합니다.
3. 브라우저로 페이지를 엽니다.

### 로컬 서버 예시

Python이 설치되어 있다면 HTML 파일이 있는 폴더에서 실행합니다.

    python -m http.server 8000

브라우저에서 접속합니다.

    http://localhost:8000

파일을 직접 여는 방식은 브라우저 보안 정책에 따라 동작이 달라질 수 있으므로 로컬 서버 사용을 권장합니다.

## 4. 게임 방법

1. 탐험가 이름을 입력합니다.
2. 난이도·모드·연산·시간·탑 모양을 선택합니다.
3. 필요하면 문제 시드를 입력합니다.
4. 플레이를 시작합니다.
5. 주사위 세 수로 만들 수 있는 목표 블럭을 찾습니다.
6. 탑을 돌려 뒤쪽 블럭도 확인합니다.
7. 블럭을 선택하고 식을 만듭니다.
8. 목표 숫자와 일치하면 블럭과 점수를 획득합니다.
9. 같은 등급의 덱이 남아 있으면 새 블럭이 채워집니다.
10. 제한 시간이 끝나거나 모든 블럭을 발굴하면 결과를 확인합니다.

### 조작

| 환경 | 조작 |
|---|---|
| PC | 마우스 드래그로 회전 |
| PC | 휠로 확대·축소 |
| 모바일 | 한 손가락 드래그로 회전 |
| 모바일 | 두 손가락 핀치로 확대·축소 |
| 공통 | 짧게 클릭·터치하여 블럭 선택 |
| 공통 | 시점 초기화로 기본 시점 복원 |

## 5. 연산 규칙

주사위 세 수를 모두 한 번씩 사용합니다.

### 사칙연산

- 덧셈
- 뺄셈
- 곱셈
- 나누어떨어지는 나눗셈

### 확장 연산

| 연산 | 조건 |
|---|---|
| 팩토리얼 | 3~6에만 적용 |
| 제곱근 | 1보다 큰 제곱수에만 적용 |
| 조합 nCr | 원본 계산 엔진의 조건 적용 |
| 거듭제곱 | 지수는 2 또는 3만 허용 |

추가 조건:

- 중간 계산 결과도 정수여야 합니다.
- 중간 결과의 절댓값 제한은 2000입니다.
- 단항 연산은 개별 주사위 수 또는 중간 결과에 적용할 수 있습니다.
- 연산에 사용한 수는 조립 과정에서 합쳐집니다.
- 잘못 조립한 경우 되돌리기로 이전 단계로 돌아갑니다.

### 풀이 보기 오답

만들 수 없는 블럭을 선택하면:

- 2점 감점
- 점수는 0점 미만으로 내려가지 않음
- 3초 후 다시 시도 가능

## 6. 난이도와 블럭 구성

덱 수는 **처음 판에 배치되는 블럭을 포함한 전체 공급량**입니다.

### 기본: 20개

| 등급 | 최초 배치 | 숫자 범위 | 점수 | 덱 |
|---|---:|---:|---:|---:|
| 최상급 | 1 | 70~96 | 15~26 | 3 |
| 상급 | 3 | 46~69 | 8~14 | 6 |
| 중급 | 6 | 21~45 | 4~8 | 10 |
| 기본 | 10 | 1~20 | 1~3 | 16 |

### 상급: 35개

| 등급 | 최초 배치 | 숫자 범위 | 점수 | 덱 |
|---|---:|---:|---:|---:|
| 최상급 | 1 | 70~96 | 15~26 | 3 |
| 상급 | 3 | 46~69 | 8~14 | 6 |
| 중급 | 6 | 31~45 | 5~8 | 10 |
| 하급 | 10 | 16~30 | 3~5 | 16 |
| 기본 | 15 | 1~15 | 1~3 | 24 |

### 공통 배치 규칙

- 현재 판 전체에서 같은 숫자가 중복되지 않습니다.
- 20을 초과하는 소수는 제외합니다.
- 같은 등급에서는 도달 가능한 주사위 굴림이 드문 숫자일수록 높은 점수를 부여합니다.
- 모양에 따라 숫자 등급과 물리적인 높이·층이 정확히 일치하지 않을 수 있습니다.
- 범위나 배치 수를 수정했다면 연산별 숫자 후보가 충분한지 다시 확인해야 합니다.

## 7. 시드와 공정한 비교

시드는 숫자 판과 주사위 순서를 재현하는 데 사용합니다.

모양 선택에는 별도의 난수를 사용하여 배경 효과나 모양 선택이 게임 난수열을 소비하지 않도록 구성했습니다.

학생끼리 비교할 때는 다음 조건을 동일하게 맞춥니다.

- 시드
- 난이도
- 실제 탑 모양
- 플레이 모드
- 연산 종류
- 제한 시간

같은 시드라도 설정이나 플레이 중 난수 소비 순서가 달라지면 이후 진행 결과가 달라질 수 있습니다.

## 8. Supabase 설정

HTML 코드의 `SUPA` 객체를 수정합니다.

    const SUPA = {
      url: 'https://프로젝트주소.supabase.co',
      key: '공개 키',
      table: 'dig_scores'
    };

### 제출 데이터

| 필드 | 내용 |
|---|---|
| name | 탐험가 이름 |
| seed | 문제 시드 |
| score | 점수 |
| taken | 발굴 수 |
| wrong | 오답 수 |
| rolls | 재굴림 수 |
| breakdown | 연산 집계와 경기 설정 |

`breakdown`은 JSON 또는 JSONB 형식이 필요합니다.

경기 설정은 `breakdown._settings`에 저장합니다.

### 주의 사항

- 브라우저 코드에는 공개용 키만 사용합니다.
- `service_role` 키를 넣으면 안 됩니다.
- 데이터베이스의 읽기·쓰기 권한과 RLS 정책을 별도로 설정해야 합니다.
- 이름 등 사용자 입력을 수집하므로 수업 운영에 필요한 최소 정보만 사용합니다.
- Supabase를 설정하지 않으면 결과 복사 기능만 사용합니다.

브라우저에서 점수를 직접 제출하는 구조이므로 부정 제출을 완전히 방지하지 못합니다. 공식 평가용으로 운영하려면 서버 측 검증이 필요합니다.

## 9. 교사 순위표

주소 뒤에 다음을 붙여 접속합니다.

    ?teacher=1

예시:

    http://localhost:8000/index.html?teacher=1

### 사용 방법

1. 학생들과 공유한 시드를 입력합니다.
2. 순위 보기를 누릅니다.
3. 제출 결과를 확인합니다.

### 표시 방식

- 5초마다 갱신
- 한 번에 최대 100건 조회
- 난이도·모양·모드·연산·시간별 그룹 표시
- 설정 정보가 없는 이전 기록은 별도 그룹 표시

100건이 조회된 경우 전체 제출 수가 100건이라는 뜻은 아닙니다.

## 10. 백분위 안내

기존 `DISTS` 표는 삭제하지 않고 보존했습니다.

다만 해당 표는 이전 판 구성을 기준으로 작성되어 다음 변경 사항을 반영하지 않습니다.

- 기본 20개 판
- 상급 35개 판
- 변경된 등급과 덱
- 입체 탐색 시간
- 모양별 난이도

따라서 화면의 백분위는 **이전 기준표를 이용한 참고값**입니다.

새 구성에 맞는 시뮬레이션 또는 실제 플레이 데이터를 확보한 뒤 재계산해야 합니다. 검증 전에는 공식 평가 지표로 사용하지 않는 것을 권장합니다.

## 11. 기술 구성

- HTML
- CSS
- JavaScript ES module
- Three.js r160
- OrbitControls
- RoundedBoxGeometry
- CanvasTexture
- Raycaster
- Supabase REST API

### 렌더링 방식

- 숫자와 점수는 CanvasTexture로 작성합니다.
- 텍스처를 블럭 여섯 면에 표시합니다.
- Raycaster로 화면에서 가장 가까운 블럭 면을 판정합니다.
- 배경은 외부 이미지가 아니라 CSS로 구성한 공중 유적 그래픽입니다.
- 주사위는 CSS로 입체감을 표현한 HTML 요소입니다.

## 13. 실행 전 점검 목록

### 파일

- [ ] 코드가 중간에서 잘리지 않았는지 확인
- [ ] 함수가 중복으로 붙여넣어지지 않았는지 확인
- [ ] 파일 끝에 `</script>`, `</body>`, `</html>`이 있는지 확인
- [ ] 브라우저 개발자 도구에 오류가 없는지 확인

### 게임

- [ ] 기본·상급 모드 모두 시작되는지 확인
- [ ] 모든 모양에서 블럭 수와 위치가 올바른지 확인
- [ ] 뒤쪽·아래쪽 블럭이 회전 후 선택되는지 확인
- [ ] 여섯 면 숫자가 정상적으로 보이는지 확인
- [ ] 드래그 후 실수로 블럭이 선택되지 않는지 확인
- [ ] 식 만들기와 풀이 보기 모두 확인
- [ ] 덱 보충과 유령 블럭 표시 확인
- [ ] 시간 종료 후 추가 획득이 차단되는지 확인
- [ ] 같은 시드와 설정의 초기 판이 재현되는지 확인

### 모바일

- [ ] 가로 스크롤이 생기지 않는지 확인
- [ ] 한 손가락 회전과 두 손가락 확대 확인
- [ ] 하단 식 조립기가 화면 밖으로 넘치지 않는지 확인
- [ ] 숫자와 연산 버튼을 누르기 편한지 확인

### 결과와 제출

- [ ] 점수와 연산 집계 확인
- [ ] 결과 복사 확인
- [ ] Supabase 제출 권한 확인
- [ ] 교사 순위표 그룹 분리 확인
- [ ] 중복 제출 여부 확인

## 14. 알려진 제한 사항

- 실제 브라우저·모바일 기기에서의 전체 테스트가 필요합니다.
- 여러 메시지로 나뉜 코드를 합칠 때 누락이나 중복이 발생할 수 있습니다.
- Three.js CDN을 사용하므로 인터넷 연결이 필요합니다.
- WebGL이 제한된 기기에서는 3D 화면을 사용할 수 없습니다.
- 현재 모양 검사만으로 모든 각도에서의 가독성과 선택 편의성을 보장하지는 않습니다.
- 모바일 저사양 기기의 성능 최적화가 필요할 수 있습니다.
- 백분위는 재계산 전 참고값입니다.
- 원본 함수 보존 여부는 자동 비교 테스트로 검증되지 않았습니다.
- Supabase 스키마와 보안 정책은 별도로 준비해야 합니다.

## 15. 생성형 AI 활용

생성형 AI를 이용하여 다음 작업을 단계적으로 진행했습니다.

1. 기존 HTML 게임 코드 분석

## 16. 권리 및 배포

- 기존 게임 코드의 이용·배포 조건을 확인해야 합니다.

- 프로젝트의 별도 라이선스는 아직 지정하지 않았습니다.
